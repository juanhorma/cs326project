## Team Roster

## Working Agreement

- We will use Discord for daily communication, questions, and project updates. We will try to respond to teammates' questions or requests within 24 hours.
- We will divide work evenly and make sure each team member has clearly assigned responsibilities for each sprint before we start working.
- We will aim to finish individual tasks at least one day before the sprint deadline to leave enough time for reviews and last minutes fixes.
- All pull requests will be considered done once it has been reviewed and approved by at least one other teammate before being merged to main.
- If we disagree on an idea or implementation decision, we will discuss possible options as a team and try to reach a consensus together.
